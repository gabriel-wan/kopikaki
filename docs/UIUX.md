# KopiKaki — User Stories

Hero-flow only, per [AGENTS.md](../AGENTS.md): build this deepest, get it working on a real phone. Everything else is stretch and cut for the hackathon.

- As Uncle/Auntie, I want to tap one big "Call KopiKaki" button and say what I feel like doing in my own words (or type it if voice fails), so that I don't need forms or gestures.
- As Uncle/Auntie, I want KopiKaki to find me a match by checking People, then Groups, then Activities, so that I rarely hear "nothing found."
- As Uncle/Auntie, I want to see who I matched with, why, and where, before I commit, so that I trust the match.
- As Uncle/Auntie, I want to confirm the meetup with one tap, so that saying yes is instant.
- As Uncle/Auntie, I want my confirmed meetup to show on the home screen afterward, so that I know the plan is real without calling again.

Cut for now: My Kakis list, accessibility settings, SOS, onboarding, notifications. Large tap targets/plain language stay in as implementation defaults, not separate stories.
